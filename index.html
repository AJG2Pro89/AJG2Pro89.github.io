El problemaThe problem

La arquitectura de referencia (Harvard, canvas-data-2-aws) carga los datos en Aurora PostgreSQL dentro de una VPC. Funciona, pero cuesta ~$77/mes solo en base de datos y red, y agregar una tabla requiere cambiar código. The reference architecture (Harvard's canvas-data-2-aws) loads data into Aurora PostgreSQL inside a VPC. It works, but costs ~$77/month in database and networking alone, and adding a table means changing code.

La soluciónThe solution

Reescritura 100% serverless: sin base de datos, sin VPC ni NAT. Lambdas orquestadas por Step Functions escriben Parquet en S3; Glue cataloga y Athena consulta. Todo desplegado como código con AWS SAM. A fully serverless rewrite: no database, no VPC or NAT. Lambdas orchestrated by Step Functions write Parquet to S3; Glue catalogues it and Athena queries it. Everything is deployed as code with AWS SAM.

Decisiones de ingenieríaEngineering decisions

TypeEnforcer

La inferencia automática de tipos generaba esquemas distintos entre particiones. Un módulo compartido fuerza cada columna al tipo canónico definido en schemas_tables_columns.csv (~1,400 columnas).Automatic type inference produced different schemas across partitions. A shared module casts each column to the canonical type defined in schemas_tables_columns.csv (~1,400 columns).

Configuración, no códigoConfig, not code

Agregar o quitar tablas es editar allow_load en un CSV y subirlo a S3. La siguiente ejecución lo toma sin redeploy.Adding or removing tables means editing allow_load in a CSV and uploading it to S3. The next run picks it up without a redeploy.

Backfill seguroSafe backfill

Script independiente para cargar el histórico de web_logs: no toca la marca de último sync, omite particiones existentes y particiona por fecha real del evento.A standalone script loads web_logs history: it leaves the last-sync watermark alone, skips existing partitions and partitions by actual event date.

Seguridad y operaciónSecurity and operations

Credenciales en SSM como SecureString, roles IAM de mínimo privilegio y un reporte diario por SNS al equipo de datos.Credentials in SSM as SecureString, least-privilege IAM roles and a daily SNS report to the data team.

Problemas reales resueltosReal problems solved

HIVE_BAD_DATA: INT64 incompatible with double

Causado por inferencia de tipos inconsistente entre particiones. Resuelto con el TypeEnforcer y un esquema canónico.Caused by inconsistent type inference across partitions. Fixed with the TypeEnforcer and a canonical schema.

Runtime.OutOfMemory

Backlogs largos de web_logs saturaban la Lambda. Se dimensionó a 10 GB de RAM y /tmp, y el backfill por bloques de días cubre los atrasos grandes.Long web_logs backlogs exhausted the Lambda. It was sized to 10 GB of RAM and /tmp, and chunked backfill handles large catch-ups.

Tablas espurias del crawlerSpurious crawler tables (day_01, month_10…)

Glue reindexaba carpetas key=value/ como tablas. Se documentó el procedimiento de recrawl limpio.Glue re-indexed key=value/ folders as tables. A clean re-crawl procedure is documented.
